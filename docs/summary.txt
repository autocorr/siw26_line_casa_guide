Summary of wiki reference documents in docs/
=============================================

vla_irc10216_casa_guide.wiki
-----------------------------
The direct model for the Jupyter notebook (last updated by Brian Svoboda for
CASA 6.5.3, then revised to 6.7.2 by Sergio Garza). Same dataset: project
TDRW0001, Ka-band (36 GHz), VLA D-array, 7 Nov 2018. Same four-field
observation:
  - J0954+1743       : complex gain calibrator
  - IRC+10216        : science target (AGB star CW Leo)
  - J1229+0203       : bandpass calibrator
  - 1331+305=3C286   : flux density scale calibrator
Two spectral windows:
  - spw 0: SiS J=2-1,  center 36.315 GHz, 64 x 125 kHz channels (~1 km/s)
  - spw 1: HC3N J=4-3, center 36.398 GHz, 64 x 125 kHz channels (~1 km/s)
Reference antenna: ea08.

Full calibration pipeline covered:
  1.  Observing logs and listobs inspection
  2.  plotants, elevation vs. time (plotms)
  3.  Prior calibrations: antenna positions (gencal caltype='antpos'),
      elevation gain curves (caltype='gc'), atmospheric opacity via
      plotweather + gencal (caltype='opac')
  4.  applycal + split to create vis_prior
  5.  Data inspection and flagging of low-amplitude time ranges
  6.  setjy for flux calibrator (3C286_A.im model, usescratch=True)
  7.  Delay calibration: gaincal gaintype='K' -> cal.dly
  8.  Pre-bandpass phase: gaincal calmode='p', solint='int' -> cal.pbp
  9.  Bandpass: bandpass solint='inf' -> cal.bp
  10. Integration-time phase solutions: gaincal calmode='p', solint='int'
      -> cal.ign (used when solving for amplitudes)
  11. Scan-time phase solutions: gaincal calmode='p', solint='inf' -> cal.sgn
      (applied to target)
  12. Amplitude+phase solutions: gaincal calmode='ap', solint='inf' -> cal.gn
  13. Flux scale: fluxscale incremental=True -> cal.flx
  14. applycal to each field with calwt=False; target uses cal.sgn not cal.ign
  15. mstransform to split out target (parallel hands only, keepflags=False)
  16. uvcontsub on line-free channels (fitspec='0~1:3~13;46~60')
  17. statwt with excludechans on line channels
  18. Optional cvel2 Doppler regridding (for maser self-cal use cases)
  19. tclean: dirty image (niter=0) to assess imaging parameters
  20. tclean: off-line channel cube to measure RMS with imstat
  21. tclean: interactive CLEAN (interactive=True, multiscale, threshold=2*rms)
  22. tclean: auto-multithresh single channel (usemask='auto-multithresh')
      with tuned noisethreshold=4.0, sidelobethreshold=1.0, minbeamfrac=0.3,
      lownoisethreshold=1.25, negativethreshold=1000.0, fastnoise=False
  23. tclean: full-cube auto-multithresh (start=1 to skip edge channel)
  24. tclean: continuum MFS image from line-free channels (specmode='mfs',
      deconvolver='hogbom', interactive=True)
  25. immoments: moments 0, 1, 2, 8 with includepix=[4*rms, 1e8]
  26. impv: position-velocity diagram
  27. specfit: two-component Gaussian fit to region-averaged spectrum
Key notes from this guide:
  - Always use calwt=False in applycal (spurious weights from VLA data)
  - Use CARTA (not CASA viewer) for image display; viewer is deprecated
  - Interrupt tclean carefully: Ctrl+C can corrupt visibilities when
    savemodel='modelcolumn' is set
  - tclean resumes from existing image by default; use rmtables() for a
    fresh start
  - Cross-hand polarizations (RL, LR) excluded via mstransform to avoid a
    CASA bug with uvcontsub + statwt
  - Data pre-processing section at the end shows how to recreate the
    TDRW0001_10s.ms from the raw SDM-BDF (importasdm, flagdata shadow/quack/
    clip, mstransform with spw='2~3' and timebin='10s')

vla_3c391_casa_guide.wiki
--------------------------
CASA 6.7.2 guide for VLA C-band continuum calibration of supernova remnant
3C 391 (April 2010, D-array, 7-pointing mosaic, 4.6 and 7.5 GHz). Covers the
standard VLA calibration workflow including polarization calibrator (3C84).
Primary calibrators: J1331+3030=3C286 (flux/bandpass), J1822-0938 (gain),
J0319+4130=3C84 (polarization). Useful as a reference for the general
calibration framework and mosaic/wide-field imaging procedures.

vla_flagging_casa_guide.wiki
-----------------------------
CASA 6.7.2 guide focused on flagging of VLA L-band data (G55.7+3.4 supernova
remnant, Aug 2010, D-array, 4 spectral windows 1.25-1.84 GHz). Covers:
  - Online flags from SDM FLAG_CMD subtable via flagcmd
  - Shadowed antennas (flagdata mode='shadow')
  - Quack flagging (flagdata mode='quack')
  - Manual RFI identification with plotms (amp vs time, amp vs freq) and
    msview (time vs channel raster display)
  - Automated RFI flagging: TFCrop (flagdata mode='tfcrop') and rflag
    (flagdata mode='rflag')
  - Flagging workflow: plot -> identify -> flag -> verify

vla_selfcal_casa_guide.wiki
----------------------------
CASA 6.7.2 guide for self-calibration using VLA C-band data of galaxy cluster
MOO J1506+5137 (Oct 2017, B-array, pipeline-calibrated). Key principles:
  - Essential first step: split CORRECTED_DATA to DATA column in new MS
  - Always start with phase-only selfcal (calmode='p') before amplitude+phase
  - savemodel='modelcolumn' is required in tclean before running gaincal
  - Verify the model was written: plotms ydatacolumn='model' should not show
    1 Jy point source
  - Explore solution intervals from solint='int' up to 'inf'; choose shortest
    interval with adequate SNR
  - gaintype='T' combines parallel hands for higher SNR (factor ~sqrt(2))
  - combine='spw' can further increase SNR if needed
  - Stop selfcal when image quality stops improving or when artifacts worsen
  - Use CARTA for image visualization and dynamic range measurement

vla_imaging_casa_guide.wiki
----------------------------
CASA 6.7.2 tutorial on imaging with tclean, using VLA L-band G55.7+3.4 data
(calibrated). Covers:
  - CLEAN algorithm: major/minor cycles, dirty beam, clean beam, residuals
  - tclean output images: .image, .residual, .model, .psf, .pb, .sumwt
  - Weighting schemes: natural (best surface brightness sensitivity),
    uniform (best resolution), Briggs robust parameter (-2 to +2)
  - uvtaper for degrading resolution to recover extended emission
  - Multi-scale CLEAN (deconvolver='multiscale', scales=[0,...],
    smallscalebias)
  - Wide-field imaging: w-projection (gridder='wproject', wprojplanes)
    and faceting
  - Wide-band imaging: MT-MFS (deconvolver='mtmfs', nterms=2) produces
    .image.tt0 and spectral index .alpha images
  - Primary beam correction (impbcor)
  - Outlier fields for bright off-axis sources
  - Image pixel size rule: 3-5 pixels across the synthesized beam FWHM
  - Cell size estimate: 42/nu_GHz arcmin for VLA primary beam FWHM
